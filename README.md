# 🚀 飞牛OS 轻量Web服务模板（Node.js + Express）

这是一个为 **飞牛OS** 开发的极简 Express Web 服务模板，可快速搭建本地 HTTP/HTTPS 接口服务，作为后续功能扩展的基础框架。

---

## 📌 项目简介
本项目是一个轻量级 Node.js + Express 后端服务，专为飞牛OS 环境设计，具备以下特点：
- ✅ 零配置即可启动基础 HTTP 服务
- ✅ 支持一键扩展 HTTPS 自签名证书
- ✅ 兼容飞牛OS 设备与移动端访问
- ✅ 适合作为飞牛OS 应用开发的后端模板

---

## 🛠️ 快速上手

### 1. 环境依赖
- Node.js 14+ （飞牛OS 自带或手动安装均可）
- npm / yarn 包管理器

### 2. 安装依赖
# 克隆项目
git clone https://github.com/你的用户名/你的仓库名.git
cd 你的仓库名

# 安装依赖
npm install express


### 3. 启动服务
#### 基础 HTTP 模式（默认）

node index.js


#### 启用 HTTPS 支持（适配移动端访问）
如需在飞牛OS 移动端或强制HTTPS的场景下访问，可按以下步骤启用HTTPS：
1.  生成自签名证书（在项目根目录执行）：
    openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes
2.  替换为 HTTPS 启动代码（可选）
